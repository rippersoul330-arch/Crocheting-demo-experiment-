# Cozy Atelier Crochet Storefront

A premium handmade crochet e-commerce demo built with Next.js, React Context, and vanilla CSS.

## Features

- Responsive home, shop, product detail, cart, and mock checkout success pages
- React Context cart state with add, remove, quantity updates, and subtotal calculation
- Category filters for Apparel, Toys, and Decor
- Vanilla CSS design system with warm artisanal styling and hover micro-animations

## Run locally

```bash
npm install
npm run dev
```

Open `http://127.0.0.1:3000` or the port shown by Next.js.

## Build

```bash
npm run build
```
